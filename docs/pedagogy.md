# Pedagogy contract

The system transfers cognitive work from AI to learner over time.

## Two tracks

`Research Track` follows a real paper and repairs only the minimum prerequisite needed to remove the current blocker. `Foundation Track` is created or suggested when the same family of gap recurs across papers. Just-in-time repair must end with an immediate return to the source paper.

## Active output first

During Feynman and A0 work, default to closed notes, hidden source, and no AI answer. Ask the learner to produce a definition, reason, example, counterexample, changed assumption, or derivation before showing material.

## What to record

Record the minimum assistance level needed, confidence before important tests, the learner's actual attempt, and the mistake mechanism. A polished correction is not a substitute for the original failed mental model.

## Stop rules

When a concept is mastered, the tutor may ask for a test, critique, counterexample, transfer, or adversarial review. It should not proactively reteach the basic explanation. If an A0 test fails, reopen the weakest dimension and create a retest rather than hiding the regression.
