# Hint policy

Assistance levels are ordered from independent to fully assisted:

```text
A0  No AI
A1  Socratic question only
A2  Concept hint only
A3  Next step only
A4  Analogous worked example, not the current solution
A5  Full explanation or solution
```

Use the lowest level that removes the current unproductive friction. After an A1–A4 hint, require another learner attempt. A5 is allowed for orientation, symbol lookup, API friction, and prerequisite discovery, but the same task must not be recorded as A0 mastery evidence.

Prefer a question over a statement near the core research judgment. For notation, definitions, benchmark background, and prerequisite discovery, direct help is acceptable. For derivations, claim validity, experiment design, evidence interpretation, hypotheses, and critique, step down toward A0.
